## 3. 서울시 정책 정보 (2025년 12월 기준)

### 3.1 청년 마음건강 지원사업
- **대상**: 만 19~39세 서울 거주 청년
- **내용**: 기본 6회 (회당 50분) 1:1 맞춤 심리상담, 필요시 4회 추가 (최대 10회)
- **검사**: 간이정신진단검사(KSCL95), 기질 및 성격검사(TCI)
- **신청**: 청년몽땅정보통 (https://youth.seoul.go.kr)
- **문의**: 다산콜센터 02-120

### 3.2 청년수당
- **대상**: 만 19~34세 서울시 거주 미취업 청년, 중위소득 150% 이하
- **내용**: 월 50만원 × 최대 6개월 지원
- **용도**: 구직 활동, 자기계발 비용

### 3.3 청년월세지원
- **대상**: 만 19~39세 서울 거주 청년 1인 가구
- **조건**: 임차보증금 8천만원 이하, 월세 60만원 이하, 중위소득 150% 이하
- **내용**: 월 최대 20만원 × 12개월 지원
- **신청**: 서울주거포털 (https://housing.seoul.go.kr)

### 3.4 청년취업사관학교 (서울 영커리언스)
- **내용**: IT, 디자인, 마케팅 등 실무 교육 및 취업 연계
- **대상**: 미취업 청년
- **특징**: AI 개발자, 디지털 전환 등 트렌드 맞춤 교육

### 3.5 위기상담 전화번호
- **자살예방상담전화**: 109 (24시간 운영)
- **정신건강상담전화**: 1577-0199 (마음이음)
- **청소년전화**: 1388
- **여성긴급전화**: 1366

## 4. SQL 형식 가이드

### 4.1 테이블 구조

```sql
-- eume_chat_list 테이블
INSERT INTO public.eume_chat_list (id, eume_user_id, chat_status, created_at, updated_at) VALUES
(user_id, user_id, 0, 'YYYY-MM-DD HH:MM:SS', 'YYYY-MM-DD HH:MM:SS');

-- eume_chat_content 테이블
INSERT INTO public.eume_chat_content (eume_chat_list_id, eume_user_id, message_type, message_content, created_at) VALUES
(chat_list_id, user_id, 'USER', '사용자 메시지', 'YYYY-MM-DD HH:MM:SS'),
(chat_list_id, user_id, 'EUME', 'EUME 응답', 'YYYY-MM-DD HH:MM:SS');
```

### 4.2 message_type
- `USER`: 사용자가 보낸 메시지
- `EUME`: AI(이음이)가 보낸 응답

### 4.3 시간 간격
- USER 메시지 후 EUME 응답: 15~30초 간격
- 다음 대화 시작: 30초~1분 간격

## 6. 작성 시 주의사항

1. **자연스러운 대화**: 실제 상담 대화처럼 자연스럽게 작성
2. **공감 표현**: EUME는 항상 공감과 이해를 먼저 표현
3. **정책 정보 정확성**: URL, 전화번호, 지원 내용 정확히 기재
4. **위기 대응**: User 12, 13은 전문 상담 연결을 최우선으로
5. **주석 포함**: 각 사용자 시나리오 시작 전 설명 주석 작성
6. **인코딩**: UTF-8로 저장 (한글 깨짐 방지)
