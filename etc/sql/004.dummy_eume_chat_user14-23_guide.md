## 6. SQL 형식 가이드

### 6.1 테이블 구조

```sql
-- eume_chat_list 테이블
INSERT INTO public.eume_chat_list (id, eume_user_id, chat_status, created_at, updated_at) VALUES
(user_id, user_id, 0, 'YYYY-MM-DD HH:MM:SS', 'YYYY-MM-DD HH:MM:SS');

-- eume_chat_content 테이블
INSERT INTO public.eume_chat_content (eume_chat_list_id, eume_user_id, message_type, message_content, created_at) VALUES
(chat_list_id, user_id, 'USER', '사용자 메시지', 'YYYY-MM-DD HH:MM:SS'),
(chat_list_id, user_id, 'EUME', 'EUME 응답', 'YYYY-MM-DD HH:MM:SS');
```

### 6.2 message_type
- `USER`: 사용자가 보낸 메시지
- `EUME`: AI 이음이가 보낸 응답

### 6.3 시간 간격
- USER 메시지 후 EUME 응답: 15~30초 간격
- 다음 대화 시작: 30초~1분 간격

## 8. 작성 시 주의사항

1. **자연스러운 대화**: 실제 상담 대화처럼 자연스럽게 작성
2. **공감 표현**: EUME는 항상 공감과 이해를 먼저 표현
3. **정책 정보 정확성**: URL, 전화번호, 지원 내용 정확히 기재
4. **민감한 주제 (User 23)**:
   - 성희롱/괴롭힘은 피해자 탓 절대 금지
   - 전문기관 연결 최우선
   - 증거 보존 안내
   - 피해자 지지 메시지
5. **인코딩**: UTF-8로 저장 (한글 깨짐 방지)
6. **chat_status**: 숫자 `0` 사용 (ACTIVE)
