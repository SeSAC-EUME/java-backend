## user - eume_chat 기능
- eume_chat_list 존재 여부 조회
  - eume_user_id 기준 조회
  - 상세 조회 기능임
  - 존재할 경우 정보를 상세 정보를 반환하고, 존재하지 않을 경우 dto에 null을 입력하여 반환
  - 이를 통해 프론트에서 eume_chat_list 생성 가능 여부 판단
- eume_chat_list 생성
  - eume_user 기준, 한 명의 유저당 하나의 eume_chat_list만 생성 가능
  - 기존에 eume_chat_list가 존재하지 않을 경우 생성 요청 가능함
  - 기존에 eume_chat_list가 존재할 경우, 생성 요청 시 에러 반환
- eume_chat_content 목록 조회 (eume_chat_list_id 기준 / pagenation)
  - eume_chat_list_id 기준으로 eume_chat_content 목록 조회
  - pagenation 적용
  - 최신순으로 정렬하여 반환
  - 페이지 번호와 페이지 크기 입력 가능
  - 기본값: 페이지 번호 0, 페이지 크기 20
  - 페이지 번호 음수 입력 시 에러 반환
  - 페이지 크기 음수 입력 시 에러 반환
- eume_chat_content 생성 (n8n 웹훅으로 eume-chat 요청)
  - eume_chat_list_id 기준으로 eume_chat_content 생성
  - eume-chat 발송 요청 시 생성
  - eume_chat_content 내용 입력 필요
  - 생성 성공 시 생성된 eume_chat_content 정보 반환
  - 생성 실패 시 에러 반환
  - eume_user_id 기준으로 eume_chat_list가 존재하지 않을 경우 에러 반환
  - eume_chat_content 내용이 비어 있을 경우 에러 반환
  - eume_chat_content 생성 시 eume_chat_list의 마지막 대화 시간 업데이트
